Kinds of cost you'll hear about

Finance and engineering slice cost differently. Know both vocabularies.

Direct vs indirect

DirectTeam salaries on the project, licenses bought for it
IndirectOffice, HR, shared tooling, split across projects

Fixed vs variable

FixedAnnual license, fixed-price vendor contract
VariableCloud usage, contractor hours, API calls

CapEx vs OpEx

CapExBuilding new software may be capitalized as an asset
OpExMaintenance, bug fixes, cloud running costs
Capitalization rules depend on accounting standards. Ask finance which work counts.

People vs cloud

PeopleOften the largest line in software projects
CloudGrows with usage, so it can surprise you after launch
Track cloud spend from day one with tags or budgets per project.

Earned value: plan vs work vs spend

Three numbers answer "are we on track?" Move the sliders or pick a preset. Tap the chart to read a week.

Status inputs

PV comes from the plan's S-curve at the status date. EV = % complete × BAC.

The S-curve

PV · planned value EV · earned value AC · actual cost
Tap the chart to read any week
  • Below 1.0 is bad for SPI and CPI. A trend over several periods matters more than one reading.
  • SPI drifts back to 1.0 near the end on late projects, since EV eventually reaches PV. Check the critical path too.
  • EAC has several formulas. BAC ÷ CPI assumes today's cost efficiency continues; AC + (BAC − EV) assumes the overrun was a one-off.

        🎯 Key takeaways

        • Time elapsed and money spent don't measure progress. Only work done (EV) tells you where you really are.
        • SPI and CPI below 1.0 mean behind and over. Watch the trend, not one reading.
        • A burn-up shows scope change; a burndown hides it.
